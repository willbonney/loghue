# Loghue

Syntax highlighting for Jenkins console logs in CloudBees CI Managed Controller (Pipeline Explorer).

Chrome and Firefox extension. Inspired by [log-syntax-highlight-ext](https://github.com/KamilMatejuk/log-syntax-highlight-ext), which recolors classic Jenkins `<pre>` consoles. Pipeline Explorer renders each log line as its own row, so Loghue targets that view instead.
